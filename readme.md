# MCPArmor —— 面向网易 开发者脚本 混淆器

## 📖 概述

**MCPArmor** 是一款专为**网易**业务场景设计的 Python 代码混淆与防逆向工具。它深度融合了**字节码层**与**抽象语法树层**的双重混淆策略，并内建针对网易运行时环境的主动反调试（Anti-Debugger）机制，能够有效提升 Python 业务代码的抗分析强度，适用于保护核心逻辑、防止外挂、逆向工程或盗版行为。

本工具在设计上兼顾**性能损耗最小化**与**混淆强度最大化**，通过多级控制流重构、字符串加密及环境指纹校验，构筑起多层安全装甲。

---

## ✨ 核心特性

### 🔐 字节码混淆（Bytecode Obfuscation）
- **OpArgs 塞死代码**  
  对字节码指令的操作数（`oparg`）进行冗余填充、乱序重组，增加静态反汇编分析难度。
- **JMP 式塞毒**  
  插入大量无效或条件永假的跳转指令（如 `JUMP_FORWARD`、`JUMP_IF_FALSE`），扰乱反编译器的控制流图。
- **反反编译**  
  注入特定魔术字节、伪造异常表条目，使主流反编译工具（如 `uncompyle6`、`pycdc`）崩溃或输出错误结构。
- **Skid 混淆器控制流**  
  采用经典的“Skid”风格控制流扁平化与伪造分支，提升动态调试追踪的复杂度。

### 🌳 AST 层混淆（基于 Python 3.13.3 引擎）
- **XOR 字符串混淆**  
  将所有静态字符串常量进行 XOR 加密，运行时动态解密，**性能稳定**且对运行时影响极小。
- **IR 式控制流**  
  将原始代码转换为中间表示（IR），并重新生成等价但结构完全不同的控制流图，破坏原始逻辑结构。
- **平坦化控制流（实验）**  
  将函数内所有基本块扁平化为一个大的 `switch` 结构，通过状态变量驱动执行流，极大提高理解难度。

### 🛡️ 反调试与环境校验（Anti-Debugger）
- **UUID(manifest) 检测**  
  读取目标环境的 `manifest` 文件（或等效标识）中的 UUID，与合法白名单比对，发现异常立即终止或触发诱饵代码。
- **_chacha（网易环境）**  
  利用网易专属的加密算法（基于 ChaCha20 变种）对关键内存区域进行校验，若环境不匹配（如模拟器、调试器附加）则拒绝执行。

## ⚙️ 系统要求

| 组件                | 最低版本要求               |
|---------------------|---------------------------|
| 混淆器主程序        | Python 2.7.18             |
| AST 处理引擎        | Python 3.13.3             |
| 目标 Python 运行时  | Python 2.7.x / 3.x（取决于被混淆脚本） |
| 操作系统            | Windows 7+ / Ubuntu 18.04+ |

> **注意**：由于 AST 模块在 Python 3.13 中引入新特性（如 `ast.unparse` 等），本工具必须使用该版本构建 AST 混淆层，并与主混淆器通过进程间通信协作。
