MCPArmor —— 针对网易环境的 Python 混淆防护套件
版本：v1.0.0
语言支持：混淆核心基于 Python 2.7.18，AST 解析引擎基于 Python 3.13.3
适用平台：网易游戏客户端、服务端脚本、工具链（Windows / Linux）

📖 概述
MCPArmor 是一款专为网易定制开发的 Python 代码混淆与防逆向工具集。它深度融合了字节码层与抽象语法树层的双重混淆策略，并内建针对网易运行时环境的主动反调试（Anti-Debugger）机制，能够有效提升 Python 业务代码的抗分析强度，适用于需要保护核心逻辑、防止外挂或盗版的应用场景。

本工具在设计上兼顾性能损耗最小化与混淆强度最大化，通过多级控制流重构、字符串加密及环境指纹校验，构筑起多层安全装甲。

✨ 核心特性
🔐 字节码混淆（Bytecode Obfuscation）
OpArgs 塞死代码：对字节码指令的操作数（opargs）进行冗余填充和乱序重组，增加静态分析难度。

JMP 式塞毒：插入大量无效或条件永假的跳转指令，扰乱反汇编器的控制流图。

反反编译：注入特定魔术字节和异常块，使主流反编译工具（如 uncompyle6）崩溃或输出错误结构。

Skid 混淆器控制流：采用经典的“Skid”风格控制流扁平化与伪造分支，提升动态调试追踪的复杂度。

🌳 AST 层混淆（Python 3.13.3 引擎）
XOR 字符串混淆：将所有静态字符串常量进行 XOR 加密，运行时动态解密，兼具性能稳定特性。

IR 式控制流：将原始代码转换为中间表示（IR）并重新生成等价但结构完全不同的控制流图。

平坦化控制流（实验）：将函数内所有基本块扁平化为一个大的 switch 结构，通过状态变量驱动执行流，极大提高逻辑理解难度。

🛡️ 反调试与环境校验（Anti-Debugger）
UUID(manifest) 检测：读取目标环境的 manifest 文件（或等效标识）中的 UUID，与合法白名单比对，发现异常立即终止或触发诱饵代码。

_chacha（网易环境）：利用网易专属的加密算法（基于 ChaCha20 变种）对关键内存区域进行校验，若环境不匹配（如模拟器、调试器附加）则拒绝执行。
